这是什么？这是一款浏览器插件，可以与某个叫Your Road Sign的网站配合使用
想要使用，直接下载配套zip即可！

Your Road Sign（路标） 是一个帮你分类收藏、管理网址的网站：
https://your-road-sign.app.workbuddy.host/
这款浏览器插件是它的配套工具，功能非常克制，只做两件事：
1. 使用次数统计：记录你访问各个网站的次数（近一周 / 一月 / 一年），在网站收藏条目的下拉信息区展示，帮你看清时间都花在了哪里
2. 新标签页常用网址：如果你在网站里设置了"常用文件夹"，可将其一键展示在浏览器新标签页上
（统计功能默认关闭，是否开启完全由你决定）

Your Road Sign网站及其配套插件还有超级多其他的功能！自由设置程度高，且完全免费！

隐私承诺
所有数据仅保存在你的浏览器本地，绝不上传。

数据只保存在浏览器本地的 chrome.storage.local 中，不经过任何服务器
不含任何统计上报 SDK，不与任何第三方共享
遵循最小权限原则：只申请实现功能所必需的权限
不想用了？关闭统计开关，或直接卸载，本地数据随插件一并清除
安装（3 步）
下载本仓库：点击上方绿色 Code 按钮 → Download ZIP，解压
打开扩展管理页：Edge 地址栏输入 edge://extensions（Chrome 为 chrome://extensions）
加载插件：打开开发人员模式开关 → 点击加载解压缩的扩展 → 选择解压出来的 extension 文件夹
更详细的图文教程见仓库中的《安装教程.html》，双击即可在浏览器打开。

使用
安装后点击浏览器工具栏的路标图标，阅读隐私声明，开启"使用次数统计"
正常上网即可，无需其他操作
在 Your Road Sign 网站 的收藏条目上点击"向下箭头"，即可看到近一周 / 一月 / 一年的使用次数
常见问题
Q：浏览器总提示"关闭开发人员模式"怎么办？ A：这是 Edge / Chrome 对未上架商店插件的常规提醒，点"不再询问"或忽略即可，不影响使用。

Q：插件代码更新了怎么升级？ A：用新的 extension 文件夹覆盖旧的，再到扩展管理页点击该插件卡片上的"重[Uploading 运行指南.md…]()
新加载"按钮。

Q：数据会不会丢失？ A：数据保存在浏览器本地，清除浏览器数据或卸载插件时会一并清除。更换电脑前，可在插件设置中导出数据文件。
